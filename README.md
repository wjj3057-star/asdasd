# 🏪 MungChi Market — 디스코드 자판기 봇 + 웹 대시보드

디스코드에서 임베드 패널 하나로 **구매 / 제품조회 / 충전 / 정보확인**을 처리하는 자동판매(자판기) 봇입니다.
잔액 충전은 **PG사 없이** 동작하는 **자동 계좌충전**과 **자동 코인충전**을 모두 지원하며,
상점명·설명·제품·재고·가격 등 모든 운영은 **웹 대시보드**에서 관리합니다.

---

## ✨ 주요 기능

### 디스코드 자판기 패널 (`/패널`)
- **상단**: 상점 이름 · **중단**: 상점 설명 · **하단**: 4개 버튼 (구매 · 제품 · 충전 · 정보)
- 상점명/설명/색상/이미지는 **웹 대시보드에서 수정 → 패널 즉시 갱신**

| 버튼 | 동작 |
|------|------|
| 🛒 **구매** | 카테고리 선택 → 제품 선택 → 수량 → 결제(잔액 차감) → **상품 DM 지급** |
| 🔎 **제품** | 전체 카테고리·제품·재고 현황 조회 |
| 🎁 **충전** | **계좌충전 / 코인충전** 선택 → 자동 잔액충전 |
| ⚙️ **정보** | 내 잔액·입금자명·누적충전/사용·구매내역 조회 |

### 자동 잔액충전
- **계좌충전 (PG 미사용)**: 입금자명 + **고유 금액**(끝자리 자동 부여)으로 매칭.
  스마트폰 입금 알림을 웹훅으로 포워딩하면 **입금 즉시 자동 충전**됩니다.
- **코인충전**: USDT(TRC20) 등. 요청마다 **고유 수량**을 부여하고, 지갑을 폴링하거나
  웹훅으로 입금을 감지해 **자동 충전**합니다.
- 두 방식 모두 자동매칭 실패 시 대시보드에서 **수동 승인/반려** 가능.
- 입금자명은 **최초 1회 입력 후 고정** (사진의 "최초 입력한 입금자명으로 고정됩니다" 규정 반영).

### 웹 관리자 대시보드
- **디스코드 OAuth 로그인** (`.env`의 `ADMIN_IDS`에 등록된 계정만 접근)
- 대시보드(통계) · 상점/임베드 설정 · 카테고리 · 제품/재고 · 충전요청 · 유저 관리
- 재고는 **한 줄에 하나씩** 대량 등록, 구매 시 순서대로 지급 (동시구매 시 중복지급 방지)

### 그 외 자동 추가 기능
- 슬래시 커맨드: `/패널` `/패널갱신` `/잔액` `/충전지급`(관리자 수동 지급/차감)
- 충전요청 자동 만료(기본 30분) · 잔액 변동 원장 · 입금알림 수신 로그
- 재고 원자적 확보로 동시 구매 경합 방지

## 🚀 설치 및 실행

### 1. 요구사항
- Node.js **18.17 이상**
- 디스코드 봇 애플리케이션 ([개발자 포털](https://discord.com/developers/applications))

### 2. 설정
```bash
npm install
cp .env.example .env   # 값 채우기
```

`.env` 핵심 항목:
| 변수 | 설명 |
|------|------|
| `DISCORD_TOKEN` | 봇 토큰 |
| `DISCORD_CLIENT_ID` / `DISCORD_CLIENT_SECRET` | 애플리케이션 ID / OAuth 시크릿 |
| `GUILD_ID` | 봇 서버 ID (슬래시 커맨드 즉시 등록) |
| `ADMIN_IDS` | 관리자 디스코드 유저 ID (쉼표 구분) |
| `WEB_BASE_URL` | 대시보드 외부 주소 (OAuth 콜백에 사용) |
| `PAYMENT_WEBHOOK_SECRET` | 입금 알림 웹훅 공유 시크릿 |
| `COIN_WALLET_ADDRESS` | (선택) 코인 자동확인용 지갑 주소 |

> 디스코드 개발자 포털 → OAuth2 → Redirects 에 `WEB_BASE_URL` + `/auth/callback` 을 등록하세요.
> (예: `http://localhost:3000/auth/callback`)

### 3. 실행
```bash
npm start          # 봇 + 웹 대시보드 동시 실행
npm run register   # (선택) 슬래시 커맨드 수동 등록
```
- 대시보드: `http://localhost:3000` → 디스코드로 로그인
- 디스코드에서 원하는 채널에 `/패널` 입력 → 자판기 설치

### 4. 초기 세팅 순서
1. 대시보드 **상점/임베드 설정**에서 상점명·설명·계좌·코인 정보 입력
2. **카테고리** 추가 → **제품** 추가 → 제품별 **재고** 등록
3. 디스코드에서 `/패널`로 패널 설치

## 💳 자동 계좌충전 연동 (PG 미사용)

PG사 대신 **스마트폰 입금 알림(SMS/푸시)을 서버로 포워딩**해 자동 충전합니다.
[MacroDroid](https://www.macrodroid.com/), Tasker, "자동 문자 전달" 류 앱에서
은행 입금 문자를 아래 엔드포인트로 **HTTP POST** 하도록 설정하세요.

```
POST  {WEB_BASE_URL}/api/webhook/bank
Header:  x-webhook-secret: <PAYMENT_WEBHOOK_SECRET>
Body(JSON):
  # 방식 A) 파싱된 값 전달 (권장)
  { "depositor": "홍길동", "amount": 10000 }
  # 방식 B) 문자 원문 전달 (서버가 자동 파싱)
  { "text": "[Web발신] KB국민 홍길동님 10,086원 입금" }
```

서버는 대기중인 계좌충전 요청 중 **금액이 일치**하고 **입금자명이 포함**된 건을 찾아
자동 승인하고 유저에게 DM으로 알립니다. 매칭 실패 건은 대시보드 **충전 요청**에서 수동 처리합니다.

## 🪙 자동 코인충전 연동
- `.env`의 `COIN_WALLET_ADDRESS`(TRON USDT-TRC20) 설정 시 30초 주기로 지갑을 폴링해 자동 확인합니다.
- 또는 외부 서비스에서 웹훅으로 통지:
```
POST {WEB_BASE_URL}/api/webhook/coin
Header: x-webhook-secret: <PAYMENT_WEBHOOK_SECRET>
Body: { "amount": "7.145321", "symbol": "USDT", "txid": "..." }
```

## 🗂️ 프로젝트 구조
```
src/
├─ index.js               # 진입점 (봇 + 웹 + 코인폴러)
├─ config.js              # 환경변수
├─ util.js                # 금액 포맷/고유금액/파서
├─ database/
│  ├─ db.js               # SQLite 스키마
│  └─ models.js           # 데이터 접근 + 잔액 원장 로직
├─ payments/
│  ├─ chargeService.js    # 충전 승인/반려 + 입금 자동매칭
│  └─ coinPoller.js       # 코인 지갑 폴링(자동확인)
├─ bot/
│  ├─ client.js           # 디스코드 클라이언트 + 슬래시 커맨드
│  ├─ embeds.js           # 자판기 패널 임베드/버튼
│  ├─ router.js           # 상호작용 라우팅
│  └─ flows/              # 구매/충전/정보/제품 플로우
└─ web/
   ├─ server.js           # Express + 세션 + OAuth
   ├─ routes.js           # 대시보드 라우트
   ├─ api.js              # 결제 웹훅
   └─ views/              # EJS 화면
```

## ⚠️ 참고
- 은행 문자 자동 파서는 은행별 형식이 달라 완벽하지 않을 수 있습니다. 정확도를 높이려면
  포워딩 앱에서 **방식 A(파싱된 값)** 로 보내는 것을 권장합니다.
- 실제 금전이 오가는 서비스이므로 HTTPS, 웹훅 시크릿, 관리자 계정 보안을 반드시 적용하세요.
