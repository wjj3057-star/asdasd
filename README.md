# 🏪 MungChi Market — 디스코드 자판기 봇 + 웹 대시보드

디스코드에서 임베드 패널 하나로 **구매 / 제품조회 / 충전 / 정보확인**을 처리하는 자동판매(자판기) 봇입니다.
잔액 충전은 **PG사 없이** 동작하는 **자동 계좌충전**과 **자동 코인충전**을 모두 지원하며,
상점명·설명·제품·재고·가격 등 모든 운영은 **웹 대시보드**에서 관리합니다.

---

## ✨ 주요 기능

### 디스코드 자판기 패널 (`/패널`)
- **상단**: 상점 이름 · **중단**: 상점 설명 · **하단**: 4개 버튼 (구매 · 제품 · 충전 · 정보)
- 상점명/설명/색상/이미지는 **웹 대시보드에서 수정 → 패널 즉시 갱신**

| 버튼 | 동작 |
|------|------|
| 🛒 **구매** | 카테고리 선택 → 제품 선택 → 수량 → 결제(잔액 차감) → **상품 DM 지급** |
| 🔎 **제품** | 전체 카테고리·제품·재고 현황 조회 |
| 🎁 **충전** | **계좌충전 / 코인충전** 선택 → 자동 잔액충전 |
| ⚙️ **정보** | 내 잔액·입금자명·누적충전/사용·구매내역 조회 |

### 자동 잔액충전
- **계좌충전 (PG 미사용)**: 입금자명 + **고유 금액**(끝자리 자동 부여)으로 매칭.
  스마트폰 입금 알림을 웹훅으로 포워딩하면 **입금 즉시 자동 충전**됩니다.
- **코인충전**: USDT(TRC20) 등. 요청마다 **고유 수량**을 부여하고, 지갑을 폴링하거나
  웹훅으로 입금을 감지해 **자동 충전**합니다.
- 두 방식 모두 자동매칭 실패 시 대시보드에서 **수동 승인/반려** 가능.
- 입금자명은 **최초 1회 입력 후 고정** (사진의 "최초 입력한 입금자명으로 고정됩니다" 규정 반영).

### 웹 관리자 대시보드 (다크 + 네온그린 디자인)
- **캡차 → 디스코드 OAuth 로그인** 2단계 인증: 로그인 전 보안 문자를 통과해야 하며, 캡차 없이 OAuth 콜백으로 직접 진입하는 우회도 차단됩니다.
  - 기본: **자체 SVG 캡차** (외부 서비스·키 불필요, 일회용 · 5분 만료)
  - `.env`에 `TURNSTILE_SITE_KEY`/`TURNSTILE_SECRET_KEY` 설정 시 **Cloudflare Turnstile** 로 자동 전환
- 상단 아이콘 내비게이션 · 페이지: **대시보드 / 상품 관리 / 카테고리 / 재고 관리 / 주문 내역 / 충전 관리 / 고객 관리 / 상점 설정**
- 대시보드: 오늘 매출·주문·재고부족·입금대기 카드, **매출 추이 차트(7일/30일)**, 시스템 라이브 상태, 자동충전 성공률, 최근 주문
- 재고는 **한 줄에 하나씩** 대량 등록, 구매 시 순서대로 지급 (동시구매 시 중복지급 방지)
- **상점 메시지 동기화** 버튼으로 설정 변경을 디스코드 패널에 즉시 반영

### 멀티 코인 충전
- 코인충전 시 **여러 코인 중 선택** 가능 — 기본 제공: **USDT(TRC20), USDT(BEP20), SOL, LTC**
- 코인별 **지갑 주소 · 환율 · 소수 자리 · 활성화**를 대시보드 **상점 설정 → 코인충전 관리**에서 편집
- 요청마다 고유 수량을 부여해 심볼/네트워크 단위로 자동 대조

### 🎮 로블록스 게임 아이템 배송 (Grow a Garden 2 등)
게임 내 트레이드로 지급되는 아이템 주문을 오케스트레이션합니다.
- 상품을 **배송 방식 = 로블록스 트레이드**로 등록 (게임명 + 게임 내 아이템명 지정)
- 구매 시 코드가 아니라 **배송 세션** 생성 → 구매자에게 자동 DM
  1. **로블록스 닉네임 등록**(모달) → 로블록스 공개 API로 **실존 확인**(userId·아바타 조회)
  2. **VIP 서버 링크 + 꼭두각시 계정** 안내 발송 (부하가 적은 서버로 자동 배정)
- 대시보드 **로블록스 배송** 탭에서 배송 큐 관리: **지급 완료 / 실패·환불 / 링크 재발송 / 서버 배정**
- **VIP 서버·꼭두각시 계정 풀** 관리 (동시 처리 한도, 활성/중지)
- 완료·실패 시 유저에게 자동 DM, **실패 시 잔액 자동 환불 + 재고 복구**

> ⚠️ **로블록스 ToS 관련 안내**: 로블록스는 게임 내 아바타/트레이드를 제어하는 공식 API를 제공하지
> 않으며, 게임 클라이언트를 매크로/인젝션으로 자동 조작하는 것은 **로블록스 이용약관 위반(계정 밴)**
> 입니다. 따라서 이 봇은 그 부분(게임 클라이언트 봇)을 포함하지 않고, **실제 트레이드는 사람 오퍼레이터
> 또는 운영자가 책임지는 외부 도구**가 수행하도록 배송 큐 API를 제공합니다.

#### 배송 처리 API (오퍼레이터/외부 워커용)
모든 요청에 `x-webhook-secret: <PAYMENT_WEBHOOK_SECRET>` 헤더 필요.
```
GET  /api/roblox/queue                        # 처리 대기 목록(배송ID, 로블닉/ID, 아이템, VIP서버, 꼭두각시)
POST /api/roblox/deliveries/:id/joined        # 유저 접속 확인
POST /api/roblox/deliveries/:id/complete      # 지급 완료 → 유저 DM
POST /api/roblox/deliveries/:id/fail          # 실패 → (기본)환불 + 유저 DM   body: { reason, refund }
```

### 🔑 월정액 라이선스 + 서버별 독립 운영 (멀티테넌트)
봇을 **여러 디스코드 서버에 판매/운영**할 수 있는 구독 시스템입니다.
- **봇 소유자**(`OWNER_IDS`)가 **일회용 15자리 키**를 발급 — 디스코드 `/키생성 <요금제> [수량]` 또는 대시보드 **라이선스 관리** 페이지
- 요금제: **1개월 / 3개월** (만료일에 이어붙임)
- 서버 관리자가 해당 서버에서 `/인증 <키>` 로 등록 → 그 서버에서 봇 기능 활성화
- **미인증/만료 서버는 자판기 기능이 잠김** (구매/충전/패널 모두 차단, `/인증`·`/구독`만 허용)
- `/구독` 으로 남은 기간 확인, 대시보드 상단에 구독 상태 표시
- **모든 데이터가 서버(길드)별로 완전 분리**: 상품·재고·카테고리·상점설정·**잔액**·충전·주문·코인·VIP서버·배송이 서버마다 독립
- 대시보드는 로그인 후 **관리할 서버를 선택**(소유자는 전체, 서버 관리자는 자신이 인증한 서버)
- **자동 만료 알림**: 만료 3일 전 / 1일 전 / 만료 시점에 라이선스를 등록한 서버 관리자에게 DM (DM 차단 시 소유자에게 통지, 재인증 시 알림 단계 초기화)
- **소유자 통합 통계**(`/owner/stats`): 전 서버 합산 매출·오늘 매출·주문, 라이선스 판매 수익 추정(요금제 가격은 `PLAN_1M_PRICE`/`PLAN_3M_PRICE` 환경변수), 서버별 매출/구독/대기 현황과 개별 대시보드 바로가기

### 그 외 자동 추가 기능
- 슬래시 커맨드: `/패널` `/패널갱신` `/잔액` `/충전지급`(관리자 수동 지급/차감)
- 충전요청 자동 만료(기본 30분) · 잔액 변동 원장 · 입금알림 수신 로그
- 재고 원자적 확보로 동시 구매 경합 방지

## 🚀 설치 및 실행

### 1. 요구사항
- Node.js **18.17 이상**
- 디스코드 봇 애플리케이션 ([개발자 포털](https://discord.com/developers/applications))

### 2. 설정
```bash
npm install
cp .env.example .env   # 값 채우기
```

`.env` 핵심 항목:
| 변수 | 설명 |
|------|------|
| `DISCORD_TOKEN` | 봇 토큰 |
| `DISCORD_CLIENT_ID` / `DISCORD_CLIENT_SECRET` | 애플리케이션 ID / OAuth 시크릿 |
| `GUILD_ID` | 봇 서버 ID (슬래시 커맨드 즉시 등록) |
| `ADMIN_IDS` | 관리자 디스코드 유저 ID (쉼표 구분) |
| `WEB_BASE_URL` | 대시보드 외부 주소 (OAuth 콜백에 사용) |
| `PAYMENT_WEBHOOK_SECRET` | 입금 알림 웹훅 공유 시크릿 |
| `COIN_WALLET_ADDRESS` | (선택) 코인 자동확인용 지갑 주소 |

> 디스코드 개발자 포털 → OAuth2 → Redirects 에 `WEB_BASE_URL` + `/auth/callback` 을 등록하세요.
> (예: `http://localhost:3000/auth/callback`)

### 3. 실행
```bash
npm start          # 봇 + 웹 대시보드 동시 실행
npm run register   # (선택) 슬래시 커맨드 수동 등록
```
- 대시보드: `http://localhost:3000` → 디스코드로 로그인
- 디스코드에서 원하는 채널에 `/패널` 입력 → 자판기 설치

### 4. 초기 세팅 순서
1. 대시보드 **상점/임베드 설정**에서 상점명·설명·계좌·코인 정보 입력
2. **카테고리** 추가 → **제품** 추가 → 제품별 **재고** 등록
3. 디스코드에서 `/패널`로 패널 설치

## 💳 자동 계좌충전 연동 (PG 미사용)

PG사 대신 **스마트폰 입금 알림(SMS/푸시)을 서버로 포워딩**해 자동 충전합니다.
[MacroDroid](https://www.macrodroid.com/), Tasker, "자동 문자 전달" 류 앱에서
은행 입금 문자를 아래 엔드포인트로 **HTTP POST** 하도록 설정하세요.

```
POST  {WEB_BASE_URL}/api/webhook/bank
Header:  x-webhook-secret: <PAYMENT_WEBHOOK_SECRET>
Body(JSON):
  # 방식 A) 파싱된 값 전달 (권장)
  { "depositor": "홍길동", "amount": 10000 }
  # 방식 B) 문자 원문 전달 (서버가 자동 파싱)
  { "text": "[Web발신] KB국민 홍길동님 10,086원 입금" }
```

서버는 대기중인 계좌충전 요청 중 **금액이 일치**하고 **입금자명이 포함**된 건을 찾아
자동 승인하고 유저에게 DM으로 알립니다. 매칭 실패 건은 대시보드 **충전 요청**에서 수동 처리합니다.

## 🪙 자동 코인충전 연동
- `.env`의 `COIN_WALLET_ADDRESS`(TRON USDT-TRC20) 설정 시 30초 주기로 지갑을 폴링해 자동 확인합니다.
- 또는 외부 서비스에서 웹훅으로 통지:
```
POST {WEB_BASE_URL}/api/webhook/coin
Header: x-webhook-secret: <PAYMENT_WEBHOOK_SECRET>
Body: { "amount": "7.145321", "symbol": "USDT", "txid": "..." }
```

## 🗂️ 프로젝트 구조
```
src/
├─ index.js               # 진입점 (봇 + 웹 + 코인폴러)
├─ config.js              # 환경변수
├─ util.js                # 금액 포맷/고유금액/파서
├─ database/
│  ├─ db.js               # SQLite 스키마
│  └─ models.js           # 데이터 접근 + 잔액 원장 로직
├─ payments/
│  ├─ chargeService.js    # 충전 승인/반려 + 입금 자동매칭
│  └─ coinPoller.js       # 코인 지갑 폴링(자동확인)
├─ bot/
│  ├─ client.js           # 디스코드 클라이언트 + 슬래시 커맨드
│  ├─ embeds.js           # 자판기 패널 임베드/버튼
│  ├─ router.js           # 상호작용 라우팅
│  └─ flows/              # 구매/충전/정보/제품 플로우
└─ web/
   ├─ server.js           # Express + 세션 + OAuth
   ├─ routes.js           # 대시보드 라우트
   ├─ api.js              # 결제 웹훅
   └─ views/              # EJS 화면
```
